
# Smart Bandwidth Allocation System
This project simulates how bandwidth is shared among multiple users
based on their data demand and priority.

Technologies Used
- C++
- Verilog
- Python (for visualization)

How to Run
1. Compile and run `bandwidth_allocation.cpp`
2. Enter total bandwidth and number of users
3. View allocation results

 Example Output
User 1 gets 35.7 Mbps
User 2 gets 17.8 Mbps
User 3 gets 46.4 Mbps
